# Vertical Slice Playtest

## 목표

이 테스트는 MMORPG를 검증하지 않는다. 계약 → 전투 → 발견 → 귀환 루프를 검증한다.

---

# 테스트 시간

플레이어 1인, 20~30분.

---

# 테스트 지역

* 하나의 도시
* 하나의 성문
* 하나의 개척지
* 하나의 폐허

---

# 테스트 무기

* 검
* 활
* 권총
* 초급 마도 촉매

---

# 테스트 장비

양손 2슬롯. **예시:** 검 + 방패, 활 + 화염, 화염 + 압축.

---

# 테스트 몬스터

* 일반 몬스터 2종
* 정예 몬스터 1종

---

# 테스트 계약

## Hunt

몬스터 처치.

## Survey

폐허 조사. 2개만.

---

# 테스트 발견

조합 발견만. **예시:** 화염 * 압축 → 화염탄.

---

# 테스트 목표

* 플레이어가 발견을 다시 시도하는가?
* 새 조합을 실험하는가?
* 계약을 다시 수락하는가?

---

# 구현 제외

* 행동 발견
* 환경 발견
* 조직
* 국가
* 종교
* 상단
* 정착지
* 도시 성장
* 세계의 의지
* 괴수
* 로열티
* 지식 거래
* NPC 이주

---

# 성공 기준

* 플레이어가 "다른 조합도 해보고 싶다"라고 느낀다.
* 플레이어가 "한 번 더 나가보자"라고 느낀다.
* 플레이어가 "이걸 팔 수 있으면 재밌겠다"라고 느낀다.

---

# 실패 기준

* 전투만 한다.
* 발견을 무시한다.
* 계약이 퀘스트처럼 느껴진다.
* 귀환 이유가 없다.
* 발견이 의미 없다.

---

# Slice 이후

성공 시: 행동 발견 추가, 환경 발견 추가, 지식 거래 추가, 정착지 추가, 괴수 추가.

실패 시: 계약 설계 재검토, 발견 설계 재검토, 전투 설계 재검토. 확장 개발 금지.
