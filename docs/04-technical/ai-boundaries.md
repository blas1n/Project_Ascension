# AI Boundaries

## 철학

AI는 세계를 운영하지 않는다. AI는 세계를 표현한다. 룰 엔진은 세계의 법이다. AI는 세계의 이야기꾼이다.

AI는 설명할 수 있다. AI는 이름을 만들 수 있다. AI는 연출할 수 있다. AI는 밸런스를 결정할 수 없다.

AI는 창조자가 아니다. AI는 기록자이다.

---

## 핵심 원칙

룰 엔진이 사실을 결정한다. AI는 사실을 표현한다. 룰 엔진은 진실의 원천이다. AI는 진실의 원천이 아니다.

---

## AI 금지 영역

AI는 아래 내용을 결정할 수 없다.

### 계약 판정

금지: 계약 성공 여부, 계약 실패 여부, 보상 지급.

### 발견 판정

금지: 최초 발견 여부, 발견 조건 충족 여부, 발견 그래프 생성.

### 전투 판정

금지: 피해량, 사망 여부, 명중 여부, 상태 이상.

### 경제 판정

금지: 가격, 소유권, 라이선스, 로열티.

### 조직 판정

금지: 주권, 시민권, 직위, 계약 권한.

---

## 허용 영역

AI는 표현을 생성할 수 있다.

### 발견 설명

허용. **예시:** 화염탄 → 설명 생성

### 술식 설명

허용. **예시:** 고공 점프 → 설명 생성

### 계약 설명

허용. **예시:** 국경 방어 계약 → 공고문 생성

### 도시 설명

허용. **예시:** 정착지 특징 설명, 건축 양식 설명

### NPC 대화

허용: 성격 표현, 소문 생성, 역사 이야기.

### 역사 기록

허용: 전쟁 기록, 도시 역사, 영웅 전설.

---

## AI 도시 생성

AI는 도시를 직접 생성하지 않는다. 룰 엔진이 도시 프로파일을 생성한다.

**예시:** 환경(설산) * 문명(군사) * 통치자(방어 성향) * 산업(광산)

### 도시 프로파일

룰 엔진 출력.

```txt
{
  climate: snow,
  culture: military,
  ruler_trait: defensive,
  economy: mining
}
```

AI는 위 프로파일을 바탕으로 건축 설명, 거리 설명, 랜드마크 설명을 생성한다.

밀림 * 자연주의 통치 * 생체 자원 → 수목형 정착지 양식 생성.

---

## 발견 생성

AI는 발견을 생성하지 않는다. 룰 엔진이 발견을 생성한다. AI는 이름을 붙이고, 설명을 작성하고, 역사를 기록한다.

**예시:** 화염 * 압축 → 화염탄 (룰 엔진이 판정) → 이름과 설명 (AI가 생성)

---

## 명성

AI는 명성을 계산하지 않는다. 룰 엔진이 계산한다. AI는 명성의 결과를 표현한다.

**예시:** 별명, 소문, NPC 반응.

---

## 세계의 의지

AI는 세계의 의지를 제어하지 않는다. World Will Simulation이 결정한다. AI는 세계의 의지의 현상을 설명한다.

**예시:** "북부 설산에서 거대한 재앙의 흔적이 발견되었다." 실제 재앙 발생 여부는 룰 엔진이 결정한다.

---

## LLM 호출 원칙

LLM은 고비용 자원이다. 모든 행동에 호출하지 않는다.

### 호출 허용

* 발견 생성 시
* 도시 생성 시
* 역사 기록 시
* 중요 NPC 대화 시

### 호출 금지

* 이동
* 전투
* 채집
* 일반 상호작용
* 반복 행동

---

## 서버 권한

* 게임 서버 → 실시간 판정
* API 서버 → 세계 상태
* LLM → 서술 생성

### 실패 처리

LLM 실패 → 게임 지속 가능. LLM 응답 없음 → 대체 텍스트 사용. 게임 로직에 영향 없음.

---

## 술식과 발견

AI는 술식 이름, 술식 설명, 세계관적 배경 설명을 생성할 수 있다.

**예시:** 화염 * 압축 → 화염탄 (룰 엔진이 판정) → 이름과 설명 (AI가 생성)

---

## 미래 확장

향후 AI는 도시 문화, 지역 전설, 역사 기록을 생성할 수 있다. 그러나 세계의 법 자체는 생성하지 않는다.

---

## 핵심 원칙

AI는 설명한다. 룰 엔진은 결정한다. AI는 세계를 기록한다. 룰 엔진은 세계를 만든다. 게임은 AI 없이도 동작해야 한다. AI는 세계를 더 풍부하게 만들 뿐이다.
