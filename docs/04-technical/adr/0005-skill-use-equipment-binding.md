# ADR 0005 — 발견 스킬은 발견 당시 장비에 묶인다

## 상태
Accepted

## 맥락

발견은 행동 + 환경 + 장비 + 지식의 상호작용으로 생성된다(discovery.md 발견 생성 요소).
예: `화염 지식 + 총(firearm) + 차징 반복 → 화염탄`.

질문: 그렇게 발견한 스킬을 **다른 장비로도 사용·재현**할 수 있는가?

- `문명 초월`(spellcraft-and-knowledge.md)은 *어떤 조합으로든 발견할 수 있다*는 원칙이다
  (`권총 × 화염술`, `검술 × 수정술`). 이는 **발견 단계**의 자유다.
- 그러나 발견 *결과*가 장비와 무관하게 아무 무기에서나 재현되면, 장비 선택이 무의미해지고
  "네 무기, 네 길"(플레이어 표현)이 약해진다.

## 결정

**발견 스킬은 발견 당시의 장비 구성에 묶인다.** 재현하려면 현재 로드아웃의 장비가 발견 당시와
**정확히 같은 집합**이어야 한다 — 양손을 통틀어 동일, **손 위치는 무관**.

- 화염탄을 화염 촉매 + 총으로 발견했다면, **그 둘을 (좌우 무관) 들고 있을 때만** 발동한다.
  촉매+검(총 없음)도, 총 하나만도 재현되지 않는다.
- 요구 장비 = 발견 시 컨텍스트의 **장비 카테고리 태그 집합**(`melee`/`firearm`/`bow`/`arcane`).
  장비 컨텍스트가 없던 발견(예: 맨몸 점프)은 요구 장비가 비어 있어 항상 사용 가능하다.
- 게이트는 결정론이다: `현재 장비 집합 == 요구 장비 집합`(부족도 초과도 불가).
  `DiscoveredSkillSet`(GameSimulation)이 판정하고, 장비 태그는 클라이언트 로드아웃에서 나온다.

이는 `문명 초월`과 충돌하지 않는다 — 발견은 자유롭게, 결과는 그 조합에 묶인다.

## 경계 / 슬라이스

- 게이트는 슬라이스에선 클라이언트/심에서 강제한다. 권위 서버에선 서버가 스킬 사용을 검증한다
  (ADR 0004와 동일한 권위 경계).
- "장비가 발견에 *본질적이었는지*"를 룰 엔진은 모른다. 단순·결정론 규칙을 택한다: 발견 시
  들고 있던 장비가 요구 장비다. 과도한 게이팅이 문제되면 추후 발현 종류(무기/커맨드)별로
  세분화한다.
