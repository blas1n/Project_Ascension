# Combat Framework

## 목적

이 문서는 Project_Ascension의 전투 시스템을 정의한다. 전투는 단순히 적을 죽이기 위한 시스템이 아니다. 전투는 발견을 위한 실험 공간이고, 원정을 가능하게 하며, 계약을 수행하게 하고, 문명 발전의 출발점이다.

---

# 핵심 철학

## 전투는 발견의 도구이다

대부분 게임: 전투 → 경험치 → 레벨업

Project_Ascension: 전투 → 실험 → 발견 → 지식

전투의 목적은 경험치가 아니다. 새로운 가능성을 찾는 것이다.

---

# 성장

## 레벨 시스템 없음

플레이어는 레벨업하지 않는다. 플레이어는 발견하고, 학습하고, 장비를 조합한다.

---

# 장비 중심 구조

직업은 존재하지 않는다. 장비 조합이 플레이 스타일을 결정한다.

## 기본 구조

* 왼손 슬롯
* 오른손 슬롯

## 예시

**예시:** 방패 + 검 / 촉매 + 권총 / 활 + 촉매 / 라이플 + 단검

---

# 무기 계열

## 근접 무기

특징: 높은 위험, 높은 기동성, 높은 발견 가능성

**예시:** 검, 도끼, 창

## 화기

특징: 정밀, 장거리, 안정적

**예시:** 권총, 소총, 산탄총

## 활

특징: 높은 유틸리티, 상태 이상, 속성 화살

## 촉매

특징: 술식 사용, 발견 확장, 보조 능력

---

# 전투 루프

## 기본 루프

탐색 → 조우 → 전투 → 실험 → 발견 → 전리품 → 귀환

전투는 항상 발견과 연결된다.

---

# 전투 자원

## 체력

생존 자원.

## 집중력

술식과 특수 행동 자원. 집중력은 마나가 아니다. 모든 계열이 사용할 수 있다.

---

# 발견과 전투

전투는 발견을 발생시키는 주요 공간이다.

## 행동 기반

**예시:** 공중 공격 반복 → 공중 사격 발견 / 회피 직후 공격 반복 → 회피 베기 발견

## 환경 기반

**예시:** 폭포 근처 전투 → 폭포 오르기 발견 / 빙벽 전투 → 빙벽 주행 발견

## 지식 기반

**예시:** 화염 + 압축 + 장거리 차징 → 화염포 / 화염 + 압축 + 근접 돌진 → 폭열 돌격

---

# 몬스터

몬스터는 단순 표적이 아니다. 몬스터는 발견의 촉매이다. 특정 몬스터는 특정 발견을 유도하고, 특정 환경을 요구한다.

---

# FPS 설계 원칙

## 높은 몰입감

플레이어는 세계를 바라보지 않는다. 세계 안에 존재한다.

## 손 기반 표현

양손 장비는 실제로 화면에 표현된다. **예시:** 왼손 — 촉매, 오른손 — 권총.

## 장비 정체성

플레이어의 정체성은 직업이 아니라 장비이다.

# 성공 기준

플레이어가 전투를 반복하는 이유가 보상 때문이 아니라 새로운 발견 때문이어야 한다. 플레이어는 강해지기 위해 싸우는 것이 아니다. 플레이어는 새로운 가능성을 찾기 위해 싸운다.

---

# 문명과 무기

각 문명은 고유한 전투 양식을 가진다.

## 화기 문명

총기 / 폭약 / 기폭술식

## 술식 문명

마도 촉매 / 술식 문자 / 자연 원소

## 근접 문명

검 / 창 / 방패 / 도끼

## 자연 문명

활 / 독 / 포자

## 플레이어

플레이어는 문명에 종속되지 않는다. 모든 무기와 술식은 조합 가능하다.

**예시:** 근접 + 화기 → 총검술 / 술식 + 자연 → 독 술식 / 화기 + 술식 → 마력 탄환 / 검술 + 수정술 → 수정 검

NPC는 일반적으로 출신 문명의 전투 양식을 따른다. 플레이어는 문명을 초월한 조합을 발견할 수 있다.

---

# 핵심 원칙

전투는 목적이 아니다. 전투는 발견의 수단이다. 발견은 성장이다. 장비는 직업이다. 플레이어는 레벨업하지 않는다. 플레이어는 세계를 이해한다.
